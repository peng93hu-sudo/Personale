两条产线的核心逻辑

调研线 PM-R 把"听说"压成"可信"

核心逻辑:多源交叉 + 红军反查
  1. 拆维度(中×3 + 意×3 = 6)
  2. 并行调研(R1/R2/R3,强制带来源)
  3. 红军逐条反查(独立第二来源)
  4. 汇总 + 缺口清单 → 你调参
  5. 出 PDF 深度报告 + HTML 看板
要点:政策(能不能做)· 经济性(划不划算)· 格局(谁在做、怎么赚)
频率:每周刷新

业务线 PM-B 把结论变成"成交闭环"

核心逻辑:选模式 → 找货 → 找客户 → 设计流程 → 算账
  1. 读调研结论 → 选最优商业模式假设
  2. B1 源端找产品/货物/服务
  3. B2 需求端找客户/成交方
  4. B3 设计中间交易结构 → B4 财务测算
  5. 红军反查 → 你拍板 → 出业务 HTML
要点:源头结果 · 成交方 · 商业模式(中间怎么赚)
频率:每天产出 1 个成果物 + 1 个可执行动作

产线频率每次必产成果物红军

PM 判断每周是否新增行业/商业模式内容的决策记录—

你的三个方向盘(决策人如何介入)

① 改参数

每个 Agent 都暴露"关键参数"(储能时长、目标省份、客户类型、分成比例…),改完重跑对应 Agent。

② 改方向

在 PM 层下达重点(如"这周研究意大利 MACSE"/"业务主攻光储充检"),PM 重新派工。

③ 拍板取舍

红军给出来源分歧时,由你裁决采信谁;裁决记入 CHANGELOG。红军判 refuted 你仍想用,需显式 override 留痕。

边界:智能体不替你做商业决策,只把"带证据的选项+风险+参数"摆到你面前;最终采信、对外动作(找客户/报价/签约)由你确认。
