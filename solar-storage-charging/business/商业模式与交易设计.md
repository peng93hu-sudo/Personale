## 2. 调研给业务的“弹药”（关键事实，决定能不能赚）

| 事实 | 数值 | 对业务的含义 | 来源 |
|---|---|---|---|
| 中国强制配储取消 | 136号文 2025-02-09 | 发电侧强配需求消失，**独立/共享储能、用户侧套利**成主战场 | [F1.1] |
| 储能成本暴跌 | 电芯 0.26 元/Wh、2h 系统中标 ~0.46 元/Wh、工商储 EPC 1.4–1.6 元/Wh | 投资门槛大降，自投/EMC 都更易算过账 | [F2.x] |
| 中国峰谷价差 | 32地均值 ~0.618 元/kWh，粤/浙/湘 >1 元/kWh | **价差>1元/kWh 的省份是工商储甜区** | [F2.x] |
| 工商储经济性 | 价差1元/kWh 下自投 IRR 28%–49%、回收 4–5 年（红军：偏乐观，需打折） | 模式成立但要保守取数 | [F2.x] |
| 公共充电桩痛点 | 利用率普遍 <7%，服务费跌至 ~0.1 元/kWh，行业普亏 | **纯充电不赚钱，必须叠加储能套利/光伏** | [F3.x] |
| 意大利电价高 | PUN 2025 ~115 €/MWh、居民 ~0.329 €/kWh（欧盟第4高） | 自发自用/CER 价值高 | [F5.x] |
| 意大利 CER 激励 | GSE 20年激励电价 60–120 €/MWh + 地理加成；PNRR 22亿€、<50000人镇 40% 资本补贴 | **CER 是补贴驱动的确定性收益** | [F4.x] |
| 意大利 Transizione 5.0 | 自发自用 PV+储能税收抵免，储能合格成本上限 900 €/kWh | 工商业自投回报被补贴抬升 | [F4.x] |
| 意大利储能容量市场 MACSE | 首拍均价 12,959 €/MW/年、10GWh、15年合同、2028交付 | 大储有**15年长约“底薪”**，可叠加套利 | [F6.x] |

> 一句话结论：**中国靠“价差套利 + 成本下降”，意大利靠“高电价 + 补贴/容量长约”**——两地都成立，但赚钱路径不同。

## 3. 三个候选商业模式假设（待你拍板选 1–2 个实跑）

### M1 · 光储充检一体化站（中国，自投 / EMC）
- **源头结果(货)**：储能系统(0.46 元/Wh)、PCS、超充桩(≥250kW，对接632号文)、光伏组件、EPC。
- **成交方(客户)**：工商业园区、物流/客运场站、充电运营商、高速服务区。
- **中间怎么赚**：① 峰谷套利(储能)；② 充电服务费；③ 光伏自发自用降电费；④ 设备集成差价；⑤（未来）V2G/虚拟电厂聚合收益 [F3.x]。
- **关键参数**：站容量、储能时长(2h/4h)、所在省价差、利用率。
- **风险**：纯充电利用率<7%(必须靠储能套利兜底)、电网接入、储能安全。

### M2 · 工商业储能 EMC（中国，合同能源管理）
- **源头结果(货)**：储能系统 + 智能运维（轻资产）。
- **成交方(客户)**：价差>1元/kWh 省份(粤/浙/湘)的高耗能工商业用户。
- **中间怎么赚**：业主零/轻投，运营方分享套利收益（典型 9:1 或 8:2），靠规模复制。
- **关键参数**：业主负荷曲线、可装容量、价差、分成比例、电池循环寿命。
- **风险**：价差收窄（2025 同比 -9.1%）、业主信用、充放次数衰减。

### M3 · CER + 户用/工商储（意大利）
- **源头结果(货/服务)**：PV+storage 设备（储能成本受 900€/kWh 上限约束）+ CER 组织运营服务。
- **成交方(客户)**：<50000人市镇、社区、中小企业、住宅业主。
- **中间怎么赚**：① 设备销售/EPC；② CER 运营服务费（组织、计量、GSE 申报）；③ 20年激励电价分成 + 40% 资本补贴落地服务 [F4.x]。
- **关键参数**：社区规模、自消费比例、装机分档、地理加成区(中/北部)。
- **风险**：官僚/审批(autorizzazioni)、并网排队(Terna)、补贴窗口(封顶5GW、截止2027/12)。

## 4. 基线交易结构（以 M2 工商储 EMC 为例，最易落地）

```
   设备源(B1)            运营平台(我方)              客户(B2,工商业主)
 ┌───────────┐   采购    ┌────────────────┐  零投资装储能 ┌────────────┐
 │ 电芯/系统  │ ───────► │ 集成+EPC+运维   │ ───────────► │ 用电企业    │
 │ 0.46元/Wh │          │ 资金/EMC合同     │ ◄─────────── │ 提供场地/负荷│
 └───────────┘          └────────┬───────┘   套利收益分成  └────────────┘
                                  │ 9:1~8:2
                          峰充谷放赚价差(>1元/kWh省份)
```
- **谁出钱**：运营平台（或融资租赁）。**谁运营**：平台。**谁分钱**：业主拿 10–20% 电费节省，平台拿大头套利。
- **利润点**：设备采购差价 + 套利收益分成 + 规模化运维。
- **风险分配**：设备质保→厂商；运营→平台；用电量波动→合同设保底。

## 5. 基线财务测算骨架（B4 待实跑；此处为口径，非承诺）

| 参数 | 中国工商储(M2) | 意大利 CER(M3) |
|---|---|---|
| 单位投资 | EPC ~1.4–1.6 元/Wh [F2] | 设备 + 安装(受900€/kWh上限) |
| 主要收入 | 峰谷套利(价差×循环×效率) | 激励电价 + 自消费省电 + 资本补贴 |
| 基准 IRR（保守取数） | 红军提示自投 28–49% **偏乐观**，建议按 12–18% 做尽调基准 | 受 40% 补贴 + 20年电价显著抬升 |
| 回收期 | 4–6 年 | 补贴到位下更短 |
| 敏感性必做 | 价差↓/利用率↓/循环衰减 | 补贴退坡/审批延迟/并网排队 |

> **红军已警示**：调研里的高 IRR(28–49%)为乐观情景，业务测算**必须**给乐观/基准/悲观三档，并以基准做决策。

## 6. 找“成交方”的路径（B1/B2 实跑指引）

- **B1 货源**：从电芯/系统集成商、超充桩厂商、EPC、（意大利）本地安装商与 GSE 申报服务商定位可获取供给，记录单价/账期/资质/交期。
- **B2 客户**：
  - 中国：价差>1元/kWh 省份的高耗能工商业、园区、充电运营商、高速服务区。
  - 意大利：<50000人市镇政府、能源社区发起方、中小企业、住宅集群。
- **触达不虚构**：B2 只产出“可触达画像 + 路径”，**具体客户名单与报价由你确认后再推进**（红军合规红线）。
