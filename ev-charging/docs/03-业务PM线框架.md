**红军给出的前提条件 / 整改项:**

1. 路径致命缺陷必须修正:绝不可执行'先A透明撮合→后B白标'的顺序。A把ODM报价对照表交到准白标客户手中=亲手销毁B赖以生存的信息不对称、制造跳单。若保留A,必须对B的目标客户隐藏货源身份,A仅作匿名询盘漏斗。
2. 首单不要押注150kW DC整桩。DC整桩同时撞上(a)小批量认证摊销吞毛利、(b)新品牌信任赤字、(c)整桩贸易救济追溯关税敞口三重杀手。首单应聚焦22kW AC wallbox或目的地慢充等低货值、低责任、低认证敏感场景,用第一单大幅让利换可验证案例,而非用DC快充直接破冰。
3. 认证成本必须从单价剥离:作为一次性合规服务费单独向客户/ODM收取,或换取ODM独家供货+认证分摊承诺,严禁摊进首单单价(否则10台量级单台摊销5000-6000欧直接击穿毛利)。
4. 贸易救济做硬预案而非软监测:在合同中加入关税追溯调整条款(税负转嫁买方或共担),持货量严格设上限以控库存追溯敞口,并将模式C(模块+意大利本地组装,享本地含量红利、规避整桩反补贴)作为主路径而非补充——这是合规结构上更抗打的选择。
5. 供给侧条款落地前不得启动:必须先书面锁定ODM的(低MOQ + ≥30天账期 + 认证分摊)三项中至少两项,否则FOB锁价/现金占用/毛利全部假设落空。拿不到则证明轻资产定位与零采购量议价能力的矛盾无法调和,应推迟。
6. 诚实重置护城河叙事:合规代办是一次性获客钩子非持续moat(认证归属型号/工厂可被复用);本地SLA外包于第三方,品牌信任需靠真实交付案例积累而非认证文件。moat实际较弱,估值与扩张节奏应据此下调。
7. 若坚持做整桩白标DC,则裁决降为no-go直至上述毛利/贸易救济前提被实测数据验证;更稳健的conditional-go路径是:模式C(卖铲子/模块)为主轴 + 模式B仅限低风险AC品类破冰 + 撮合A匿名引流。

> 红军采用"杀死这门生意"原则。**裁决为 no-go,意味着推荐路径在当前形态下不成立,须按上述条件整改后复评。** 这正是"每次更新都经红军反查"机制的价值:在投入真金白银前先证伪。

## 一、最优商业模式初判(B4)

### 🏆 推荐:模式B:本地品牌白标分销+EPC交钥匙(以模式A撮合做冷启动引流)

在'6-12个月首单、毛利>15%、合规可落地、轻资产优先'四约束下,模式B总分最高且最均衡(成交速度5、可行性5)。它命中意大利决策链最短的客户层(EPC/安装商/目的地/车队居家wallbox),这是公开数据中明确'最易成交、毛利可>15%'的轻资产渠道;同时贴本地品牌+本地SLA解决了纯撮合(模式A)粘性低、易跳单的根本缺陷,也避免了模式D/E的高合规复杂度与重履约/现金占用。建议以模式A的撮合+合规代办能力作为获客与现金流的冷启动引擎(几乎零资本即可跑通首批PoC),验证供需后顺势升级为模式B的白标分销,把一次性撮合变成可复购、可标杆复制的本地品牌业务;并对高毛利缺口品类引入模式C的液冷枪线/模块供货增厚毛利。这是一条'轻起步(A)→建粘性(B)→提毛利(C)'的递进路径,而非单点押注。

### 撮合机制(中国货源↔意大利CPO/进口商)
- **目的**:用最低成本撮合'符合合规与功率门槛的中国直流桩/超充模块/液冷枪线供应商'与'意大利主导CPO及整桩组装商',在6-12个月内促成首单。以B端供货撮合为主,规避C端品牌与渠道壁垒(研究businessOpportunities #1/#3)。先打小批量PoC样机单破冰,再绑定2027年合计超2.5万桩的招标管线。
- **规则**:四步漏斗:①需求建档——按CPO/进口商录入采购品类(整桩/充电模块/液冷枪线/V2G模块)、目标功率(≥150kW走廊桩、单站≥600kW)、接口(CCS2+Type2)、合规要求(CE/RED EN18031/CEI 0-21/0-16/OCPP+ISO15118)、账期与年化采购量;②供方筛——只放行已过或承诺6个月内过CE+RED的中国厂商,强制硬门槛(接口=CCS2、IP/防护、CCC背书);③智能匹配——按'合规就绪度×功率匹配×报价×交期×产能'加权打分,输出TOP-N并生成样机PoC建议;④撮合成单——先1-2台样机现场验证(含CEI并网),验证通过转批量框架协议。匹配低于阈值则触发'合规改造/接口改造'需求回流给货源方。撮合成功以'签署框架协议或PoC采购单'计,而非仅意向。
- **节奏**:需求/供方库实时更新;匹配批处理每周1次;PoC进度与招标管线日历每两周复盘1次

| 参数 | 默认值 | 说明(决策人可调) |
|---|---|---|
| `matchScoreThreshold` | 0.70 | 撮合放行的综合匹配分阈值(0-1)。调高=只推高确定性成单线索、转化率高但线索少;调低=扩大撮合面、适合冷启动铺量。冷启动期建议0.65 |
| `matchWeights` | 合规就绪0.30/功率与接口匹配0.25/报价0.20/交期0.15/产能与财务稳健0.10 | 匹配打分权重。意大利硬约束是合规与接口,故合规权重最高;若决策人优先抢单可上调报价权重,优先稳交付可上调交期/产能权重 |
| `complianceGate` | 必须已持有或承诺≤6个月取得 CE(LVD+EMC)+EN 61851/62196 接口+RED EN 18031 | 一票否决硬门槛开关。可放宽为'仅样机阶段可豁免RED',以加速PoC;但批量单不可豁免(合规即护城河) |
| `pocBatchSize` | 1-2台/SKU | 破冰样机台数。调大可加速客户信任但占用样机预算与认证样品;首单建议2台(1台测试1台并网验证) |
| `minOrderValue` | 5万欧元(样机单可降至0) | 进入批量撮合的最小订单额下限,过滤低价值询盘;样机/PoC单不设下限以促首单 |
| `targetSegments` | 高速/走廊超快充>主导CPO城市快充>目的地充电(酒店/商超/车队)>南部及岛屿错位市场 | 撮合优先级排序(研究机会#2/#9)。决策人可重排:抢规模选CPO招标,抢毛利选模块/液冷枪线隐形冠军路线 |

### 分润/分账机制(平台佣金与渠道激励)
- **目的**:作为撮合平台/贸易服务方,在不重资产的前提下用佣金+服务费+里程碑分账获取收益,同时用阶梯返佣激励货源方让利、激励本地渠道/认证伙伴拉单,确保平台与各方利益对齐且毛利可控(目标平台侧毛利>15%)。
- **规则**:分润分四层:①平台撮合佣金——按成交GMV收取基础佣金,样机/首单可减免以促成;②合规增值服务费——代办CE/RED/CEI认证、OCPP联网与ISO15118集成、按kWh价格透明合规方案,按项目固定费+成功费收取(认证周期本身即护城河,研究#4);③本地渠道/BD返佣——给意大利本地BD或认证/安装伙伴按成交比例返佣,激励拉单与本地履约;④里程碑分账——货款按'签约/到港/验收并网'三段释放,平台在每段按比例计提服务收益。复购与大单走阶梯降佣,锁定长期管线。
- **节奏**:佣金随订单结算(按里程碑);返佣月度结算;阶梯费率每季度按累计GMV重定档

| 参数 | 默认值 | 说明(决策人可调) |
|---|---|---|
| `platformCommissionRate` | 整桩交易3%/模块·枪线核心件5%/纯撮合介绍1.5% | 平台基础佣金率。模块/液冷枪线毛利更高故佣金更高(研究#3);决策人可整体上下调以平衡'抢量vs抢利',抢量期可降至2% |
| `complianceServiceFee` | 固定8-15万元/项目 + 成功费GMV的2% | 合规代办服务定价。这是核心壁垒变现项;可对战略大客户减免固定费、提高成功费,把现金收益后置换取大单 |
| `channelRebateRate` | 成交额的1-2% | 本地BD/渠道返佣率。调高加速本地拓客但摊薄平台毛利;南部/错位市场可单独上浮至3%激励开荒 |
| `milestoneSplit` | 签约30%/到港40%/验收并网30% | 里程碑回款与分账三段比例。提高'验收并网'尾款比例=对买方更友好、利于成单但平台/货源方现金回收慢;需与风控账期联动 |
| `tieredDiscountThresholds` | >50万欧元降佣0.5pct;>200万欧元降佣1pct | 阶梯降佣触发GMV档位。门槛越低越激进让利换大单;头部CPO招标单建议直接进顶档 |
| `supplierRebateForCompliance` | 货源方让利的20%返还(用于补贴其改接口/认证) | 对承担接口改造/认证的货源方的激励回返比例,降低其出海门槛、保障供给 |

### 定价机制(报价锚定与让利空间)
- **目的**:以'中国直流桩制造成本约欧洲一线1/3、外销毛利40%+'为成本底,以意大利本土进口替代价为天花板,锚定一个既显著低于欧洲一线、又锁定>15%净毛利的报价带;并对超快充/液冷枪线等稀缺缺口品类做溢价,对走量CPO招标做规模让利。
- **规则**:三锚定价:①成本锚——FOB出厂成本(含接口/认证改造分摊);②竞品锚——欧洲一线品牌(ABB等)对意报价为天花板,目标定价为其55-70%(仍远高于中国成本,故毛利充裕);③缺口锚——意大利>50kW快充仅约22%、走廊缺口大,对≥150kW超快充与液冷枪线核心件给稀缺溢价。落地价=max(成本×(1+目标毛利), 竞品价×折扣系数),叠加关税(HS8504约0-3.7%,按TARIC 10位码逐码核)、物流、认证摊销与汇率缓冲。设价格透明合规模式(按kWh)作为软性卖点而非降价。
- **节奏**:标准报价单季度复核;汇率/铜价(液冷枪线)波动超阈值即时重定价;招标单一单一议

| 参数 | 默认值 | 说明(决策人可调) |
|---|---|---|
| `targetGrossMargin` | 整桩22%/模块·液冷枪线30%/超快充缺口品类35% | 目标毛利率下限(满足约束>15%并留缓冲)。这是核心旋钮:抢首单/抢招标可临时降至18%,稀缺品类挺价可上调 |
| `competitorDiscountFactor` | 欧洲一线对意报价的60% | 竞品锚折扣系数。调低=更激进抢份额(因中国成本仅1/3仍盈利),调高=维持品牌价值与毛利;首单破冰可下探至55% |
| `scarcityPremium` | ≥150kW超快充+8%、液冷超充枪线+10% | 缺口/稀缺品类溢价。需求强制(AFIR)+本土不产,可挺价;若巨头自研替代出现则下调 |
| `fxBuffer` | EUR/CNY 报价含3%汇率缓冲,锁汇覆盖>60%敞口 | 汇率缓冲与锁汇比例。意大利收欧元、成本付人民币,缓冲过低易被汇率吃掉毛利,过高则报价缺竞争力 |
| `tariffAssumption` | HS8504按2.0%计提(区间0-3.7%,逐码核实) | 关税计提假设。需按TARIC 10位码核实;若欧盟对充电设备启动贸易救济(研究风险#5),上调并触发本地化预案 |
| `certAmortizationPerUnit` | 认证总成本(数十万元/套)按首批200台摊销 | 认证成本单台摊销基数。批量越大单台摊得越薄;小单首单建议单列认证服务费而非摊进单价以免报价失真 |
| `incoterm` | 首单CIF热那亚/的里雅斯特;成熟后DDP | 贸易术语默认值。CIF降低平台履约责任利于冷启动;DDP对买方省心利于绑定大客户但平台承担清关/合规风险 |

### 风控机制(信用·合规·交付·政策)
- **目的**:在需求侧脆弱(BEV渗透5-6%、利用率15-20%、补贴依赖)、巨头议价强、跨境收款与政策不确定的环境下,系统性控住坏账、合规退运、交付违约与政策/贸易救济四类风险,保住首单不亏、毛利不被风险吞噬。
- **规则**:四道闸:①信用闸——对买方做KYC与信用评级(主导CPO信用好可放宽,中小进口商需信保/预付/LC),设单客户敞口上限;②合规闸——发货前强制核验CE/RED/CEI/OCPP/ISO15118文件齐全与样机并网通过,合规不齐不发运(防退运与罚则);③交付闸——SO/T(船期)、QC验货、质保金与备件承诺,延期按日计违约金;④政策/贸易闸——监测AFIR/2035灵活化修订、欧盟对华贸易救济动向,设触发器联动定价(关税)与本地化预案(近岸/欧盟建厂,研究#7)。买方违约/弃单(如Be Charge弃逾1600站点的需求波动风险)以预付+里程碑回款+信保兜底。
- **节奏**:信用评级季度复评、大单单评;合规闸每单发货前;政策监测每周扫描;敞口与坏账月度看板

| 参数 | 默认值 | 说明(决策人可调) |
|---|---|---|
| `buyerCreditPolicy` | 主导CPO(Enel X Way/Be Charge/Ewiva/Atlante等):30%预付+OA60;中小买方:50%预付+余款LC/信保 | 按买方信用分层的收款政策。预付比例越高越安全但越难成单;头部CPO可纯OA账期换大单 |
| `creditInsuranceCoverage` | 中信保覆盖应收的≥80%,保费计入定价 | 出口信用保险覆盖比例。需求侧脆弱与弃单风险下建议强制投保;覆盖越高坏账风险越低、毛利侵蚀越多 |
| `maxSingleBuyerExposure` | 单一买方未保险净敞口≤平台月GMV的25% | 单客户集中度上限,防巨头依赖与弃单冲击;招标大单须配套信保或LC才可突破 |
| `paymentTerms` | 账期OA净60天(NET60);超90天进黑名单 | 标准账期旋钮。延长账期是对意大利买方的关键让利筹码,但直接占用平台/货源方现金、放大坏账,需与信保联动 |
| `complianceHoldGate` | 开启(CE/RED/CEI/OCPP文件+样机并网未通过则锁运) | 合规放行闸开关。关闭可抢时间但承担退运/罚则/品牌风险,强烈建议常开 |
| `latePenaltyRate` | 交付延期0.3%/天,上限合同额5%;质保金合同额5%/12个月 | 对货源方的交付违约金与质保金。调高保障买方体验但可能吓退中小货源方 |
| `policyTriggerWatch` | 监测项:AFIR目标/2035灵活化立法、对华充电设备贸易救济、PNRR支出截止 | 政策/贸易风险触发清单。命中即联动关税计提上调与本地化建厂评估;决策人可增减监测项与告警阈值 |
| `fxHedgeRatio` | 对已签约欧元应收锁汇≥60% | 汇率对冲比例,与定价fxBuffer配合;锁汇越高毛利越确定但放弃汇率有利波动收益 |

### 履约机制(交付·并网·售后闭环)
- **目的**:以轻资产模式完成'中国出厂→意大利清关→现场安装并网→联网调试→质保运维'的端到端履约,把中国成熟运营/选址/潮汐调度know-how(研究#10)产品化为EPC/运维增值服务,保障首单按时按质交付并形成复购,把单纯卖货升级为高粘性解决方案。
- **规则**:六段闭环:①备货与认证样品确认→②出厂QC+装箱+订舱(按incoterm)→③清关与CEI 0-21/0-16并网文件交付→④本地安装伙伴现场安装+OCPP联网+ISO15118即插即充调试→⑤验收(功率/接口/支付互操作/按kWh价格透明)签收触发里程碑回款→⑥质保+备件SLA+远程运维(可叠加利用率优化/潮汐调度增值服务)。每段设KPI与超时告警,异常回流风控闸。本地化运维与备件库轻资产化:用本地安装/运维伙伴网络而非自建,关键备件(模块/枪线)设近岸寄售库降低停机。
- **节奏**:订单级里程碑跟踪(签约→到港→并网→验收);质保期内运维按SLA响应;履约KPI月度复盘

| 参数 | 默认值 | 说明(决策人可调) |
|---|---|---|
| `leadTimeTarget` | 样机45天/批量整桩90天/模块·枪线60天(出厂到港) | 交期目标。压缩交期提升竞争力但需备货占款;首单建议留10-15天缓冲避免延期违约 |
| `warrantyPeriod` | 整桩24个月/核心模块36个月 | 质保期。延长利于成单与对标欧洲品牌,但抬高质保金与售后成本;超快充/模块按部件分级保更优 |
| `sparePartsBuffer` | 近岸寄售备件库:模块/枪线按在役设备的5%备货 | 备件库存比例。提高可把停机降到最低(对冲意大利南部可靠性差痛点),但占用资金;轻资产用伙伴寄售 |
| `installPartnerModel` | 认证本地安装/运维伙伴网络(非自建团队) | 本地履约模式。伙伴网络=轻资产、快上量;自建团队=质量可控但重、慢。冷启动强烈建议伙伴模式 |
| `slaResponseTime` | 远程响应24h/现场48h(北部)·72h(南部岛屿) | 运维SLA响应时效。提速提升客户满意与复购,但需更密本地伙伴覆盖与备件;南部可单列宽限 |
| `acceptanceCriteria` | 额定功率达标+CCS2/Type2接口+OCPP联网+ISO15118即插即充+按kWh价格透明+CEI并网通过 | 验收标准清单(触发尾款)。标准越严越护品牌、越利长期绑定,但拉长验收周期、压后回款 |
| `valueAddedOps` | 默认随附:利用率诊断+潮汐调度建议;V2G/虚拟电厂方案为可选增购 | 增值运维打包开关(研究#6/#10)。把中国运营know-how变现、提升客户ROI与粘性;V2G随ISO15118-20(2027)前置卡位 |
